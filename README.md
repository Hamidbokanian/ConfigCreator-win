# Config Finder برای ویندوز

سازنده: حمید بوکانیان — 09378976737

کانفیگ‌های v2ray / vless / vmess / trojan / shadowsocks رو دانلود می‌کنه، **با هسته‌ی Xray واقعاً تستشون می‌کنه** و خودش بهشون وصل میشه.

## روش ۱: ساخت exe روی GitHub (پیشنهادی)
1. یه مخزن (repository) جدید بساز و همه‌ی فایل‌های این پوشه رو آپلود کن (پوشه‌ی `.github` هم باید باشه).
2. تب **Actions** ← **Build Windows** ← **Run workflow**.
3. بعد از چند دقیقه، پایین صفحه‌ی اجرا از بخش **Artifacts** فایل `ConfigFinder-Windows` رو دانلود کن.
4. داخل zip این فایل‌ها هستن: `ConfigFinder.exe`، `xray.exe`، `wintun.dll`. **همه رو کنار هم نگه دار** و `ConfigFinder.exe` رو اجرا کن.

## روش ۲: بدون ساخت exe (با پایتون)
1. Python 3.9 یا بالاتر نصب کن (موقع نصب «Add python.exe to PATH» رو بزن).
2. `xray.exe` رو از صفحه‌ی Releases پروژه‌ی XTLS/Xray-core (فایل `Xray-windows-64.zip`) دانلود کن و کنار `main.py` بذار. برای حالت VPN کامل `wintun.dll` هم لازمه (از wintun.net).
3. روی `run.bat` دابل‌کلیک کن.

برنامه توی مرورگر باز میشه (آدرسش فقط روی همین کامپیوتر کار می‌کنه). پنجره‌ی سیاه رو نبند؛ بستنش برنامه رو خاموش می‌کنه و تنظیمات پروکسی ویندوز رو به حالت قبل برمی‌گردونه.

## طرز کار
- **مرحله ۱:** پینگ اتصال (TCP) از خود کامپیوتر؛ فقط سرورهای زیر سقف پینگ (پیش‌فرض ۱۵۰ms) می‌مونن. برای TLS/Reality هندشیک TLS هم چک میشه.
- **مرحله ۲:** هر کانفیگ توی یه پردازش Xray اجرا میشه و یه درخواست HTTPS واقعی (`gstatic.com/generate_204`) از داخلش رد میشه. فقط اون‌هایی که واقعاً کار کردن می‌مونن.
- **اتصال خودکار:** بهترین کانفیگ رو وصل می‌کنه؛ اگه ترافیک رد نشد تا ۴ تای بعدی رو امتحان می‌کنه.
- دو حالت اتصال:
  - **پروکسی سیستم** (پیش‌فرض، بدون Admin): پروکسی ویندوز روی 127.0.0.1:10809 تنظیم میشه (SOCKS5 هم روی 10808 هست). مرورگرها و برنامه‌هایی که پروکسی سیستم رو می‌خونن ازش رد میشن.
  - **VPN کامل (TUN):** همه‌ی برنامه‌ها. باید `ConfigFinder.exe` رو با Run as administrator باز کنی و `wintun.dll` کنار `xray.exe` باشه.
- سایت‌های `.ir` پیش‌فرض مستقیم (بدون پروکسی) باز میشن؛ از تنظیمات قابل خاموش کردنه.
- اگه برنامه وسط کار ببنده یا کرش کنه، بار بعدی که اجرا بشه تنظیمات پروکسی ویندوز رو خودش برمی‌گردونه.

## محدودیت‌ها (صادقانه)
- پینگ واقعی یه درخواست کامل HTTPS از داخل پروکسیه، پس معمولاً چند برابر پینگ TCP هست. سقف پیش‌فرضش ۱۵۰۰ms هست و در تنظیمات قابل تغییره.
- کانفیگ‌های `allowInsecure` و ترنسپورت‌های kcp/quic تست نمیشن.
- حالت TUN رو فقط با داکیومنت رسمی Xray پیاده کردم و اینجا نتونستم روی ویندوز واقعی امتحانش کنم.
- بعضی آنتی‌ویروس‌ها فایل‌های exe ساخته‌شده با PyInstaller رو اشتباهی هشدار میدن؛ در این صورت از روش ۲ استفاده کن.
- مجوز نرم‌افزارهای همراه: Xray-core (MPL-2.0)، Wintun (مجوز فایل‌های آماده‌ی wintun.net).
